# DFT Database

This section provides access to quantum chemical calculation results for sweetener compounds included in the Extreme Sweet Database.
A total of 278 molecules were optimized at the DFT level using the B3LYP functional and 6-311++G(d,p) basis set.  For each molecule, 
optimized 3D geometries, infrared (IR) spectra, Raman spectra, and Raman activity analyses are provided.

## Available Data:

- **Optimized 3D Structures:** Interactive molecular visualization tools allow users to explore and download the calculated geometries.
- **Infrared Spectra:** Normalized IR spectra visualized interactively; multiple compounds can be compared.
- **Raman Spectra:** Normalized Raman spectra available for interactive analysis and comparison.
- **Raman Activity Data:** Visualization of Raman activity profiles across wavenumbers.

These datasets enable researchers to investigate the structural and vibrational properties of sweeteners and support molecular interpretation 
efforts through interactive tools.
